RUNTIME demonstrates the full product lifecycle rather than a small demo:

- React/TypeScript frontend with responsive desktop and mobile UI
- Server-authoritative PHP/MySQL game engine and private multiplayer rooms
- Singleplayer bots, guided tutorial, deck building, boosters and progression
- Reactive German, English and Dutch localization
- Installable offline-capable PWA with automated rules, i18n and build checks
- Public documentation covering architecture, rules, cards, security and contribution workflows
